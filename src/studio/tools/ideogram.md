# Ideogram — зураг (текст бичдэг)

Сүүлд шалгасан: 2026-09-27 · Баримт: https://ideogram.ai/

## Промптын бүтэц
```
[scene description], with the text "WORD" in [font style], [style], [aspect]
```
Дэлгэцэн дээрх текстийг **хашилтад** бич. Латин үсгийг бусад загвараас хамаагүй
зөв бичдэг — гэхдээ **кирилл найдваргүй**.

## Параметрүүд
- Харьцаа: 1:1, 16:9, 9:16, 4:5, 3:2 (интерфейсээс сонгоно)
- **Magic Prompt** — промптыг автоматаар дэлгэрүүлнэ. Тодорхой хяналт хэрэгтэй бол **унтраа**.
- Стилийн сонголт: Auto / General / Realistic / Design / 3D / Anime
- Negative prompt талбартай

## Давуу / сул
- **Давуу:** постер, лого, баннер шиг **текстэй** дизайнд хамгийн сайн; **үнэгүй хувилбартай**
  (өдөрт хязгаартай удаан горим).
- **Сул:** гэрэл зургийн бодит чанар Midjourney-оос сул; кирилл үсэг гажина.

## Түгээмэл алдаа
| Алдаа | Засвар |
|---|---|
| Монгол текст гажсан | Латинаар бич, эсвэл текстгүй гаргаад Canva дээр нэм |
| Урт текст эвдэрсэн | 1–3 үгээр хязгаарла |
| Промпт өөрчлөгдсөн | Magic Prompt-ыг унтраа |
