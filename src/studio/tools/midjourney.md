# Midjourney — зураг

Сүүлд шалгасан: 2026-09-27 · Баримт: https://docs.midjourney.com/

## Промптын бүтэц
```
[subject] [action] [setting], [style], [lighting], [composition] --ar 4:5 --stylize 250 --no text
```
Англиар, таслалаар тусгаарласан богино хэллэгүүд. Урт өгүүлбэр бичихээс илүү
**тодорхой нэр үг + тодотгол** үр дүнтэй.

## Параметрүүд
| Параметр | Утга | Тайлбар |
|---|---|---|
| `--ar` | `1:1`, `4:5`, `9:16`, `16:9`, `3:4` | Харьцаа. FB пост 4:5, Reels 9:16 |
| `--no` | `--no text, watermark` | Хориглох зүйл |
| `--stylize` (`--s`) | 0–1000, анхдагч 100 | Өндөр = уран сайхан, prompt-оос хазайна. Бүтээгдэхүүнд 50–150 |
| `--chaos` (`--c`) | 0–100 | Өндөр = 4 хувилбар илүү өөр. Санаа хайхад 20–40 |
| `--seed` | тоо | Ижил seed = ойролцоо үр дүн. Дүрийг давтахад |
| `--q` | 0.5, 1, 2 | Нарийвчлал ба цаг |
| `--sref <url>` | зургийн холбоос | Стилийн лавлагаа |
| `--cref <url>` | зургийн холбоос | Дүрийн тогтвортой байдал |

## Давуу / сул
- **Давуу:** уран сайхны чанар хамгийн өндөр; стиль нэгтгэх сайн.
- **Сул:** **үнэгүй хувилбар байхгүй** (төлбөртэй, сард ~$10-аас); Discord эсвэл вэб
  дээр ажиллана; **текст, ялангуяа кирилл огт болохгүй**.
- Монголоос: карт төлбөр хийх боломжтой бол ажиллана.
