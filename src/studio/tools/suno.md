# Suno — хөгжим

Сүүлд шалгасан: 2026-09-27 · Баримт: https://suno.com/ · https://help.suno.com/

## Хоёр талбар
Suno дээр **Style** ба **Lyrics** гэсэн хоёр талбар байна — хоёуланг нь тусад нь бич.

### Style (хөгжмийн промпт, англиар)
```
[genre], [mood], [tempo], [instruments], [vocal type], [production style]
```
Жишээ: `warm acoustic folk, hopeful, 90 bpm, acoustic guitar and light strings, female mid-range breathy vocal, clean modern production`
- **Хоолойн төрлийг заавал бич** (female mid-range / male tenor / duet with harmonies).
- Instrumental хэрэгтэй бол Lyrics-ээ хоосон орхиод `instrumental` гэж сонго —
  видеоны дэвсгэр хөгжимд ихэвчлэн энэ нь зөв.

### Lyrics (үг)
Бүтцийн шошгыг ашигла:
```
[Verse]
…
[Chorus]
…
[Bridge]
…
[Outro]
```
`[Guitar Solo]`, `[Instrumental Break]` гэх мэт шошго ажиллана.

**Ажиллахгүй шошго:** `[Reverb: 30%]`, `[BPM: 120]`, `[Bass: 80%]` гэх мэт
параметр хэлбэрийн шошгыг Suno уншдаггүй — зүгээр л зай эзэлнэ. Ийм зүйлийг
Style талбарт **үгээр** бич ("slow 90 bpm", "heavy reverb").

## Хязгаар
- Бүртгүүлэхэд **5 үнэгүй кредит**, карт шаардахгүй. Түүнээс хойш өдрийн үнэгүй
  кредит болон төлбөртэй төлөвлөгөө байдаг — хэмжээ нь өөрчлөгддөг тул сайтаас шалга.
- Загварын хувилбар хурдан солигддог (v5 → v5.5 → v6). Шинэ хувилбар сонгогдсон эсэхийг шалга.

## Монгол хэл
Монгол дуу үг Suno дээр **дуудлага гажих магадлалтай**. Найдвартай хувилбар:
**instrumental** гаргаад CapCut дээр монгол ярианаа тавих.
