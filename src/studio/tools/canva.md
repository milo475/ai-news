# Canva — дизайн, текст нэмэх

Сүүлд шалгасан: 2026-09-27 · Баримт: https://www.canva.com/help/

## Юунд хэрэглэх вэ
Canva бол **промптын хэрэгсэл биш, эцсийн угсралтын хэрэгсэл**. AI-аар гаргасан
зургийг энд оруулж **монгол текстээ зөв фонтоор** нэмнэ. Промпт студийн урсгалд
бараг үргэлж сүүлийн алхам болно.

## Алхам
1. Шинэ дизайн → хэмжээгээ сонго (FB пост 1080×1080 эсвэл 1080×1350; Reels 1080×1920).
2. Uploads → AI-аар гаргасан зургаа оруул.
3. Text → монгол фонт сонго. **Кирилл дэмждэг фонт**: Roboto, Open Sans, Montserrat,
   Lato, Noto Sans. (Олон гоёмсог фонт кирилл дэмждэггүй — үсэг алга болно.)
4. Брэндийн өнгөө hex кодоор тавь (Brand Kit төлбөртэй, гэхдээ өнгийг гараар оруулж болно).
5. Download → PNG (зураг) эсвэл MP4 (видео).

## Magic Media (Canva доторх AI)
Текстээс зураг үүсгэнэ. Үнэгүй хувилбарт **тоо хязгаартай**. Чанар нь Midjourney-оос
сул ч дизайны дотроос шууд ашиглахад хялбар.

## Давуу / сул
- **Давуу:** үнэгүй хувилбар хангалттай; монгол фонт ажиллана; загвар (template) олон.
- **Сул:** уран сайхны зураг үүсгэх чадвар дунд; зарим элемент төлбөртэй (титэм тэмдэгтэй).

## Түгээмэл алдаа
| Алдаа | Засвар |
|---|---|
| Монгол үсэг алга болсон | Кирилл дэмждэг фонт сонго (Roboto, Montserrat) |
| Текст зураг дээр уншигдахгүй | Хагас тунгалаг хар давхарга (rectangle, opacity 40%) нэм |
| Татахад титэм гарч ирэв | Тэр элементийг үнэгүйгээр сольж болно |
