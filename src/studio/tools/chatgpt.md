# ChatGPT — текст, зураг

Сүүлд шалгасан: 2026-09-27 · Баримт: https://help.openai.com/en/articles/9275245-chatgpt-free-tier-faq

## Промптын бүтэц (текст)
```
Үүрэг: [чи хэн бэ]
Даалгавар: [юу хийх]
Хэн уншина: [сонсогч]
Өнгө аяс: [албан ёсны / энгийн]
Урт: [N үг / N догол мөр]
Хэлбэр: [жагсаалт / хүснэгт / захидал]
Жишээ: [1–2 жишээ өгвөл чанар мэдэгдэхүйц дээшилнэ]
```
**Хамгийн үр дүнтэй нэмэлт:** хүссэн хариуныхаа **жишээг 1–2** өгөх.

## Зураг
- Хэлбэр: ярилцлага дундаас зураг гаргана, дараа нь «энэ өнгийг өөрчил» гэж **үгээр засварлана**.
- Текст бичих чадвар сайн (латин). Кирилл — найдваргүй.
- Үнэгүй хэрэглэгч: **24 цагт ойролцоогоор 2–3 зураг**. Төлбөртэйд хамаагүй олон.

## Давуу / сул
- **Давуу:** монгол хэл сайн ойлгодог; засварыг ярианы аргаар хийнэ; үнэгүй хувилбартай.
- **Сул:** үнэгүй зургийн хязгаар бага; уран сайхны чанар Midjourney-оос сул;
  урт бичвэрт заримдаа зохиомол баримт (hallucination) оруулна — **тоо, огноо, нэрийг шалга**.

## Түгээмэл алдаа
| Алдаа | Засвар |
|---|---|
| Хариу ерөнхий, ус шиг | Сонсогч, урт, хэлбэрийг заа. Жишээ өг |
| Монгол найруулга «орчуулга шиг» | «Ярианы монгол хэлээр, богино өгүүлбэрээр» гэж нэм |
| Зохиомол баримт | «Эх сурвалж мэдэхгүй бол мэдэхгүй гэж хэл» гэж нэм |
