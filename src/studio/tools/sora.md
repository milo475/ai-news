# Sora (OpenAI) — ХААГДСАН, БҮҮ САНАЛ БОЛГО

Сүүлд шалгасан: 2026-09-27 · Баримт: https://help.openai.com/en/articles/20001152-what-to-know-about-the-sora-discontinuation

## Төлөв
OpenAI Sora-г хаасан:
- **Вэб/апп — 2026-04-26-нд зогссон.**
- **API — 2026-09-24-нд зогссон.**

Тиймээс Sora-г хэрэглэгчид **санал болгохгүй**. Хэрэв хэрэглэгч Sora гэж нэрлэвэл
хаагдсаныг эелдэгээр хэлээд доорх орлуулалтыг санал болго.

## Орлуулалт
| Sora-гийн юунд | Оронд нь |
|---|---|
| Дуутай, бодит видео | **Veo** (дуу промптоос гарна) |
| Үнэгүй, өдөр бүр | **Kling** (өдөрт 66 кредит) |
| Зургаас видео, камерын хөдөлгөөн | **Runway** |
| Богино эффект, хямд туршилт | **Pika** |
