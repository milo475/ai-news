# CapCut — видео угсралт, субтитр

Сүүлд шалгасан: 2026-09-27 · Баримт: https://www.capcut.com/

## Юунд хэрэглэх вэ
AI-аар гаргасан 4–8 богино клипийг **нийлүүлэх**, хөгжим тавих, **монгол субтитр**
бичих. Утсан дээр ч, компьютер дээр ч үнэгүй.

## Алхам (Reels/TikTok)
1. New project → Canvas харьцааг **9:16** болго.
2. Клипүүдээ дарааллаар нь оруул. Клип бүрийн уртыг 2–4 секунд болго.
3. Шилжилт (transition) — энгийнийг л: Cut эсвэл Dissolve. Гоёмсог шилжилт сонирхлыг бууруулна.
4. Audio → хөгжмөө оруул. Дууны түвшинг 20–30% болго (яриа сонсогдохын тулд).
5. Text → монгол текстээ бич. Кирилл дэмждэг фонт сонго.
6. **Captions → Auto captions** нь монгол хэл дэмжихгүй байж болзошгүй — субтитрээ
   гараар бичих нь найдвартай.
7. Export → 1080p, 30fps.

## Давуу / сул
- **Давуу:** бүрэн үнэгүй, утсан дээр ажиллана, монгол фонт дэмжинэ.
- **Сул:** зарим AI функц (авто субтитр) монгол хэлийг муу таньдаг; усан тэмдэг
  (watermark) гарахаас сэргийлж экспортын өмнө төгсгөлийн CapCut клипийг устга.
