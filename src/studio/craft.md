# Кино, зургийн хэл — монгол тайлбартай

Энэ файл нь промптод хэрэглэх мэргэжлийн нэр томьёог агуулна. Студи нь хэрэглэгчид
**монголоор тайлбарлаж**, промптод **англиар** бичнэ.

Сүүлд шалгасан: 2026-09-27

## Кадрын хэмжээ (shot size)

| Англи | Монгол | Хэзээ |
|---|---|---|
| extreme wide shot | маш өргөн кадр | газар орныг харуулах, эхлэл |
| wide shot / establishing | өргөн кадр | хүн + орчин хоёулаа |
| medium shot | дунд кадр (бэлхүүснээс дээш) | яриа, үйлдэл |
| medium close-up | цээжин кадр | ярьж буй хүн, ярилцлага |
| close-up | ойрын кадр (нүүр) | сэтгэл хөдлөл |
| extreme close-up | маш ойрын кадр (нүд, гар) | нарийн деталь, hook |
| over-the-shoulder | мөрөн дээгүүр | хоёр хүний яриа |
| point of view (POV) | нүдээр нь харах | үзэгчийг оролцуулах |

## Линз, гүн

- `35mm` — байгалийн, баримтат өнцөг
- `50mm` — хүний нүдтэй ойр, бүх нийтийн
- `85mm portrait lens` — хөрөг, арын дэвсгэр бүдгэрнэ
- `wide 24mm` — орон зай томоор, ирмэг гажина
- `shallow depth of field` / `f/1.8` — арын дэвсгэр бүдэг, гол объект тод
- `deep focus` — бүгд тод, мэдээллийн

## Композиц

- `rule of thirds` — гол объектыг гуравны нэгийн шугам дээр
- `centred composition` — тэгш хэмтэй, албан ёсны
- `leading lines` — зам, хашлага нүдийг хөтөлнө
- `negative space` — хоосон зай (**текст тавихад хэрэгтэй**)
- `foreground element` — урд талд юм тавьж гүн нэмэх

## Стиль

- `documentary photograph` — бодитой, зохиомол биш
- `cinematic still, 35mm film look` — кино кадар
- `editorial photography` — сэтгүүлийн
- `product photography, studio lighting` — бүтээгдэхүүн

- `3D render, soft studio light` — орчин үеийн, цэвэрхэн
